💱 Конвертер валют KZT

Лёгкий автономный конвертер валют, заточенный под казахстанский тенге. 
Работает в браузере как один HTML-файл — без сервера, без сборки, без зависимостей.
Зачем это нужно

Большинство онлайн-конвертеров либо не учитывают тенге вообще, либо тянут курс из источника, которому сложно доверять напрямую. Этот инструмент сравнивает курс сразу из нескольких источников и не ломается, если один из них недоступен.

Возможности
Конвертация между 6 валютами: KZT, USD, RUB, CNY, EUR, AED
Трёхуровневый fallback при получении курса: НБК РК → Open Exchange Rates → Frankfurter, а если недоступны все три — используются захардкоженные резервные курсы, чтобы конвертер не переставал работать вообще
Полностью автономный — один HTML-файл, работает офлайн (кроме самого запроса курса)
Не требует установки: открыл файл в браузере — и готово
Как это выглядит

Интерфейс сделан по собственному наброску-скетчу — минимум лишних элементов, фокус на самом расчёте.

Технологии

HTML / CSS / JavaScript — без фреймворков и сборщиков.

Запуск локально
bash
git clone https://github.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ.git
cd РЕПОЗИТОРИЙ

Просто открой index.html в браузере.

⚠️ На iPhone файл нужно открывать напрямую через приложение «Файлы» в Chrome — при открытии через Notion курсы не подгружаются.

Как работает fallback курсов
Запрос курса отправляется в Национальный банк РК.
Если НБК недоступен — запрос уходит в Open Exchange Rates.
Если недоступен и этот источник — используется Frankfurter.
Если все три источника недоступны — конвертер использует захардкоженные резервные значения курса, чтобы интерфейс оставался рабочим в любом случае.
